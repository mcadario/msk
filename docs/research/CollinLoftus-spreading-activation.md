# Collins & Loftus (1975) — Spreading-Activation Theory of Semantic Processing

## 1. Main idea

- Semantic memory = **network**.
- Concepts = **nodes**.
- Relations/properties = **links** between nodes.
- Processing / priming concept `X` → activation spreads from `X` through connected links.
- Related concepts receive activation → easier/faster subsequent processing.
- Search can begin from >1 node → spreading activation may meet at an **intersection**.
- Once intersection reaches sufficient activation → evaluate connecting path → semantic decision.

**Basic intuition:**

`prime X → spread activation → related nodes partly activated → less additional activation needed → faster RT`

---

## 2. Starting point: Quillian's semantic-memory theory

Quillian:

- concept = node
- properties represented by labeled relational links
- links can differ in **criteriality / accessibility**
- memory search = parallel spreading from starting concept nodes
- activation leaves a trace/tag as it spreads
- tags from different starting nodes meet → intersection found
- path back to starting nodes can then be reconstructed/evaluated

Priming uses same mechanism:

`prime concept → activation tags spread outward → later concept needs less search to intersect`

Important: links themselves can effectively be primed, not only concept nodes.

---

## 3. Misinterpretations of Quillian rejected by Collins & Loftus

### Cognitive economy

Distinguish:

- **strong cognitive economy**: property stored only at highest/general level → lower concepts inherit it.
- **weak cognitive economy**: information may be redundantly stored when experience makes that useful.

Authors defend the **weak** version.

→ Do **not** assume every property is stored exactly once.

### Equal links? No.

Links differ in accessibility/strength.

`frequently used relation → stronger / more accessible link → faster processing`

So e.g. category links for typical exemplars can be stronger than for atypical exemplars.

### Rigid hierarchy? No.

Semantic memory is **not necessarily a strict taxonomic tree**.

Network can encode many relations + cross-connections.

### Parallel search ≠ independent runners

Parallel spreading can share a limited activation resource.

→ more paths/concepts activated can dilute activation.

# 4. Extended spreading-activation theory

## Local processing assumptions

### A1 — Activation spreads + attenuates

Processing concept `X`:

`X → neighbors → neighbors of neighbors → ...`

Activation decreases with distance.

Decrease depends inversely on link accessibility/strength.

`strong link → more activation transmitted`

`weak link → less activation transmitted`

### A2 — Continued processing maintains activation

Longer processing/rehearsal of `X` → activation continues to be released from `X` at a fixed rate.

Central processing limitation:

- only one concept actively processed at a time
- BUT activation already released continues spreading in parallel

### A3 — Activation decays

Activation ↓ with:

- time
- intervening activity

Therefore priming is temporary.

`prime → delay ↑ → priming effect ↓`

### A4 — Intersection uses a threshold

Activation arriving from different sources **sums**.

When summed activation at an intersection ≥ threshold:

`intersection fires → connecting path evaluated`

→ explains why prior activation can reduce RT.

---

# 5. Global structure of semantic memory

## A5 — Semantic network organized by semantic similarity

More properties shared between concepts → more interconnections → greater semantic relatedness.

Not just shortest-path distance.

Semantic relatedness ≈ aggregate of connections between concepts.

Example from Fig. 1:

```text
vehicle ↔ car / truck / bus / ambulance / fire engine
red ↔ fire engine / fire / apples / cherries / roses / sunsets ...
```

Important consequence:

`prime vehicle → activation concentrated among interconnected vehicles`

but

`prime red → activation distributed across many diverse red-associated concepts`

→ same total activation can be **diffused differently**.

## A6 — Separate lexical network

Concept names stored in a **lexical / dictionary network**.

Lexical network organized mainly by:

- phonemic similarity
- partly orthographic similarity

Name node ↔ one or more semantic concept nodes.

So:

`word form ≠ concept itself`

Semantic + lexical processing can interact.

## A7 — Strategic control of priming

Person can control whether activation is directed toward:

- lexical network
- semantic network
- both

Control = diffuse activation of a whole network/region + source-specific activation from stimulus.

→ task expectations can alter priming.

---

# 6. Semantic matching / decision process

Question form:

`Is X a Y?`

Decision ≠ necessarily one fixed search strategy.

Evidence accumulates until:

- positive criterion reached → **YES**
- negative criterion reached → **NO**
- neither reached before evidence exhausted → **DON'T KNOW**

Positive + negative evidence can partially cancel.

## A8 — Evidence accumulation

Different paths found in memory contribute evidence.

`Σ positive evidence` vs `Σ negative evidence`

Decision when one threshold is exceeded.

---

# 7. Main types of semantic evidence

## A9 — Superordinate connections

Direct category relation can be decisive.

Example:

`mallard → duck → bird`

→ strong positive evidence that mallard = bird.

Negative superordinate relation can provide strong negative evidence.

## A10 — Property comparison

Shared/matching properties → positive evidence.

Distinguishing/mismatching properties → negative evidence.

Weight depends on **criteriality**.

Important asymmetry:

- one highly criterial mismatch may strongly support NO
- YES usually requires multiple strong matches

Superordinate + property evidence can combine.

## A11 — Wittgenstein strategy

Compare X to known instances of Y.

Example:

`stagecoach ? vehicle`

Compare stagecoach with car-like instances.

Shared properties → positive evidence.

Differences → negative evidence.

Difference from ordinary property comparison:

- Wittgenstein strategy weights matching + distinguishing properties more symmetrically.

## A12 — Mutually exclusive subordinates

If X and Y belong to mutually exclusive subcategories → strong negative evidence.

Example:

`mallard = duck`

`duck` and `eagle` treated as mutually exclusive bird kinds

→ evidence that `mallard ≠ eagle`.

Authors note this is not universally valid; depends on domain/knowledge.

## A13 — Counterexamples

Universal statement can be rejected by retrieving a counterexample.

Example:

`All birds are canaries`

retrieve `robin` → bird but not canary → reject.

General:

`claim: all X are Y`

`find Z: Z ∈ X AND Z ∉ Y → NO`

# 8. Priming predictions

Core mechanism:

`prior activation → target closer to threshold → RT ↓`

Strength depends on:

- semantic relatedness
- link accessibility
- amount of activation
- number of concepts sharing activation
- elapsed time
- task strategy
- lexical vs semantic preparation

### Diffusion principle

Fixed/limited activation spread across more concepts → less activation per concept.

Thus:

`small coherent semantic set → strong priming/member`

`large diffuse set → weak priming/member`

---

# 9. Loftus production experiments

Task: produce category member satisfying cue.

Example:

- `fruit + A`
- `fruit + red`

Main result:

`category first → faster than adjective/letter first`

Explanation:

`fruit first → activation spreads to relatively small, interconnected set of fruits`

→ apple, pear, peach, orange, lemon... become primed.

But:

`red first → huge heterogeneous set of red things`

or

`A first → huge set of A-words`

→ activation more diffuse → weaker preparation of relevant fruit.

Hence:

`category-first RT < adjective/letter-first RT`

---

# 10. Direction / frequency effects

Association can be asymmetric.

If concept A strongly evokes B but B weakly evokes A:

`prime A → B strongly activated`

`prime B → A weakly activated`

So RT depends on **directional accessibility**, not merely symmetric similarity.

Production frequency treated as measure of path strength/accessibility.

`higher association frequency → stronger priming → faster intersection → lower RT`

---

# 11. Lexical vs semantic preparation

Letter cues can prepare lexical network; adjectives can prepare semantic network differently.

Task structure matters.

If participant knows a letter is coming:

`prepare lexical network → letter trials faster`

If trial type uncertain/mixed:

activation resources may be distributed differently.

Figure 2:

- adjective RT ~ similar across mixed/blocked conditions
- letter RT becomes much faster in blocked condition

Interpretation:

`expectation → strategic network priming`

---

# 12. Repetition / lag effects

Retrieving item activates related items.

Example:

`retrieve fruit member X`

→ spreads activation to nearby fruit members

→ subsequent retrieval of another fruit member facilitated.

But activation decays (A3):

`intervening items ↑ → activation ↓ → facilitation ↓`

Therefore:

`short lag → faster RT`

`long lag → RT returns toward baseline`

Paper links this mechanism to semantic facilitation in lexical decision as well.

---

# 13. Juola & Atkinson — multiple categories

Task: decide whether word belongs to any of 1–4 target categories.

Observed:

`# target categories ↑ → categorization RT ↑`

Authors' spreading-activation explanation:

limited activation divided among target categories.

`more categories → activation/category ↓`

→ harder discrimination → slower decision.

Also activation from previous trials persists but decays.

So RT depends on:

- target-set size
- recency of previous targets
- difficulty of discriminating target vs non-target

Key claim:

Results fit a **parallel activation model** better than simple serial category search.

---

# 14. Conrad sentence-verification study

Task: true/false judgments, e.g.

`A salmon can eat.`

Earlier Collins & Quillian result:

property farther from instance in hierarchy → RT ↑.

Spreading-activation interpretation:

`instance + property far apart → activation takes longer to intersect → RT ↑`

Conrad argued property frequency could explain effects.

Authors' response:

- weak cognitive economy allows common properties to be stored at several levels
- high-frequency property → more likely direct/local storage → less inference → faster RT
- some of Conrad's comparison/methodology weakens her challenge
- her second experiment is more problematic but also has methodological issues because prior presentation can prime superordinates

Bottom line:

Conrad ≠ decisive refutation of spreading activation.

---

# 15. Typicality effects

Typical members categorized faster than atypical members.

Example:

`robin → bird` faster than `chicken → bird` / `goose → bird`.

Two explanations in theory:

### 1. Competing evidence

Atypical item has distinguishing properties.

`chicken → bird`

positive evidence: category link

BUT properties like size/farm use/etc. distinguish chicken from typical birds

→ negative/competing evidence slows YES.

### 2. Link accessibility

Frequently used category relation → stronger link.

`robin → bird` used often → strong accessibility

`chicken → bird` used less often → weaker accessibility

→ slower spread/intersection.

Thus:

`typicality ↑ ↔ category-link accessibility ↑ ↔ RT ↓`

---

# 16. Semantic unrelatedness & negative decisions

For clearly unrelated concepts:

`book ? dog`

search mostly finds distinguishing relations/properties → negative criterion reached quickly.

But semantic relatedness does **not always** predict negative RT in same direction.

Why? Different decision strategies can be used.

Examples:

- mutually exclusive subordinate strategy
- counterexample strategy
- property mismatch

→ RT depends on **kind of evidence used**, not semantic distance alone.

This is a major point of the paper: semantic decisions are flexible.

---

# 17. Relation to Smith, Shoben & Rips feature model

Smith et al.:

concept = bundle of semantic features.

Features divided into:

- **defining** features
- **characteristic** features

Categorization roughly:

1. compare all features
2. if similarity clearly high → YES
3. clearly low → NO
4. intermediate → second-stage check of defining features

Collins & Loftus objections:

### Defining vs characteristic distinction is problematic

Natural categories often have no single absolutely necessary feature.

`remove wings from bird → still bird`

People also often cannot state defining properties for familiar categories.

### People use superordinate knowledge

Feature-only model ignores category links even when known.

Authors argue:

`why ignore relevant superordinate information if it is stored?`

### Their own model is more flexible

Can use:

- superordinate links
- matching properties
- mismatching properties
- mutually exclusive categories
- counterexamples
- instance comparisons

Feature matching = only one possible evidence source.

---

# 18. But the theories overlap

Collins & Loftus acknowledge Smith et al. captures important feature-comparison behavior.

A revised feature model with continuously accumulated feature evidence could resemble their own decision process.

Key difference:

`Smith et al. → mainly feature evidence`

`Collins & Loftus → multiple evidence types + spreading activation network`

They treat feature comparison as a **special case** of a more general semantic-decision mechanism.

---

# 19. Why such a complicated theory?

Authors' argument:

Human knowledge is incomplete + irregular.

People often lack:

- explicit defining features
- particular superordinate links
- complete category information

Therefore one rigid decision algorithm cannot work for every semantic judgment.

Need flexible procedure:

`available knowledge configuration → available evidence → decision strategy`

So complexity reflects variability in stored knowledge.

At a higher level, they argue the theory is actually simple:

- network
- activation spread
- evidence accumulation
- Bayesian-like decision from available evidence

---

# 20. Big-picture model

```text
stimulus / prime
      ↓
activate concept node(s)
      ↓
activation spreads in parallel
      ↓
strength determined by link accessibility
      ↓
activation attenuates + decays
      ↓
related nodes become partially activated
      ↓
activation from multiple sources sums
      ↓
intersection reaches threshold
      ↓
retrieve/evaluate path(s)
      ↓
accumulate + / − semantic evidence
      ↓
positive criterion → YES
negative criterion → NO
neither → DON'T KNOW
```

# 21. High-yield takeaways

**Semantic memory**

`concepts = nodes`

`relations = weighted/accessibility-sensitive links`

**Spreading activation**

`process X → activation spreads from X`

`distance ↑ / link strength ↓ → activation ↓`

**Priming**

`prime related concept → target preactivated → RT ↓`

**Limited activation**

`# activated concepts ↑ → activation/concept ↓`

**Decay**

`time/interference ↑ → activation ↓ → priming ↓`

**Relatedness**

`more shared/interconnected properties → stronger semantic relation`

**Typicality**

`strong/frequent category connection + less conflicting evidence → faster categorization`

**Decision**

`evidence accumulation → threshold`

Evidence may come from category links, properties, exemplars, exclusivity, counterexamples, etc.

**Main theoretical move**

Quillian-style semantic network + flexible spreading activation + flexible evidence-based decisions.

---

# 22. One-sentence summary

**Semantic processing = activation spreading through a flexible, similarity-organized network; prior activation changes accessibility, and semantic judgments occur when accumulated evidence reaches a decision threshold.**
